dependencies and are not bundled.

bundling another package, add it here.

### Feather-derived icons (ISC-covered, additionally MIT per lucide's own LICENSE)

Lucide's own `LICENSE` file states that a subset of its icons are derived from the
[Feather](https://feathericons.com) project and additionally carries Feather's MIT notice for
those icons specifically. Cross-checking that list (resolved through lucide's alias map — see
`scripts/generate-icon-packs.mjs`) against the 65 distinct icons this library's four packs
actually ship (`scripts/icon-packs.json`'s `featherDerived`, regenerated by
`npm run generate-icon-packs:write` and cross-checked by `scripts/check-icon-packs.mjs`) gives
exactly 8 shipped icons that are Feather-derived: `calendar`, `chevron-right`, `circle`,
`ellipsis`, `feather`, `octagon`, `triangle`, `triangle-exclamation-point` (ships as this
library's `basic` pack's `triangle-alert`/`TriangleAlert`, via lucide's own alias). The Feather MIT
notice below is scoped to exactly these 8 shipped icons' path data, on the basis of that
per-icon audit — it is not a blanket "every lucide icon is also Feather" statement.
